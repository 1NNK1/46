# 🔄 Рефакторинг Redux Toolkit с асинхронными действиями (ДЗ 46.1)

Проект демонстрирует переход от синхронного управления состоянием к асинхронному с использованием Redux Thunk (`createAsyncThunk`).

## 🚀 Реализованный функционал
Приложение загружает список пользователей из внешнего API (`jsonplaceholder.typicode.com`) и управляет состояниями загрузки и ошибок.

## 🛠 Технические особенности
- **createAsyncThunk**: Используется для создания асинхронного экшена `fetchUsers`.
- **Extra Reducers**: В слайсе реализована обработка трех состояний жизненного цикла асинхронного запроса:
  - `pending`: Установка флага `loading = true` (показывается лоадер).
  - `fulfilled`: Сохранение полученных данных в `entities`.
  - `rejected`: Сохранение текста ошибки для отображения пользователю.
- **Разделение логики**: Асинхронные действия вынесены в отдельную папку `asyncActions` для лучшей организации кода.

## ⚙️ Запуск проекта
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
